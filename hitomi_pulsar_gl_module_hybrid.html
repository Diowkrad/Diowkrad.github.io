  1. Сначала TOOLS (шаги 1–4 из секции выше) — иначе экспорт не поедет.

5 · Сборка «гибрид» (этот файл)
  1. ШАР — из стенда: аналитическое пересечение луча со сферой, поверхность через shadeStarSurface (кора fbm, горячие шапки на полюсах, Френель).

  4. Тонмаппинг стенда (ACES + гамма) + дизеринг модуля в конце.
  5. Для игры: оба прохода переносятся в ветку k==6 как есть — метки ПРОХОД 1 / ПРОХОД 2 стоят в коде.
