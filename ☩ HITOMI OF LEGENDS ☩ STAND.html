ЗАМЕТКА: куда добавлять в игре.
1. Звёздную поверхность в игре рисует шейдер фона #glbg. Блок «сфера звезды» находится во фрагментном шейдере glbg по ветке starHit (сферический ЛОД-2 звезды, там же счёт короны col += uSunC*pow(max(dStK,0.0), 6.0)*0.35*uSunB;).
2. Вставь функции random3 / noise / fbm / pattern из этого стенда ВЫШЕ main() шейдера glbg (рядом с уже живущими там fbm3 — конфликтов имён нет, здесь суффикс ST).
3. В ветке starHit вместо плоского sphCol считай: vec3 nrm = normalize(hitPos - uStarPos); → float n = STpattern(nrm*uScale + vec3(0.0, uTime*uTS), q, r); → col = mix(mix(mix(c1, c2, r.z), c3, q.x), c4, n); где c1..c4 = fx.surf.ln1 / c1 / sp1 / sp2 звезды (уже приходят uniform-ами или добавь один uniform vec3 uStarPal[4]).
4. Размер маски в игре не нужен отдельным слайдером: диск звезды задаёт ray-sphere hit, «маска» = сам hit-круг, а лимб-затемнение smoothstep(1.0, 0.15, length(uv)) бери из локального UV пересечения.
5. Производительность: pattern() = 7 вызовов fbm. На весь экран тяжело; в игре звезда занимает малую часть кадра — приемлемо. Если нужен разгон: в интеграции обрезай pattern до n = fbm(p + 4.0*q) (2 fbm вместо 7) — теряется ~20% выразительности.
6. 2D-фолбэк для игры не требуется: glbg — уже WebGL. Фолбэк в стенде ниже — только для машин без WebGL, там паттерн считается в JS на тайле 96×96 и натягивается клипом.
