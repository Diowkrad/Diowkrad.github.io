SF2 ENGINE v1.2.5 «Finale» — сборка из модулей
================================================

Структура:
  project/
    index.html          — каркас страницы: порядок подключения и место под разметку
    css/style.css       — сюда переносится CSS из исходного HTML (пока заготовка)
    js/                 — скрипт, разрезанный по заголовкам-секциям:
      01_state.js           состояние, лог, LCD, аудиограф (ensureAudio)
      02_chip_engine_2a03.js CHIP-движок 2A03
      03_sf2_parser.js       ПАРСЕР SF2 (RIFF/LIST + RIFX + сигнатурный поиск)
      04_sf2_playback.js     воспроизведение SF2
      05_sustain.js          сустейн 1/8 · 1/4 · 1/2
      06_sensitivity.js      ТУШЕ: soft / hard / fixed
      07_sf2_loader.js       загрузка SF2, пресеты, инструменты
      08_keyboard_mouse.js   клавиатура (мышь) + ленты скролла + замок ролла
      09_keyboard_pc.js      клавиатура ПК
      10_midi_keyboard.js    MIDI-клавиатура (Web MIDI)
      11_midi_gm128.js       MIDI GM × 128 (v1.1.1 «GLOBAL MIDI»)
      12_start.js            СТАРТ: инициализация и логи
      13_touch_fps.js        touch-детект + FPS-метр

Правила сборки:
  1. ПОРЯДОК ПОДКЛЮЧЕНИЯ МЕНЯТЬ НЕЛЬЗЯ — модули делят общие
     константы и Map'ы (state, activeChip, activeSF2, activeMidi).
     Атрибут defer гарантирует порядок исполнения.
  2. Каждый файл — самостоятельный модуль: от одного заголовка-секции
     до следующего. В начало каждого добавлена шапка с номером.
  3. CSS лежит в css/style.css. В разрезанном .txt стилей не было —
     пришлите HTML, перенесу 1:1.
  4. Разметку интерфейса вставьте в <body> index.html вместо комментария.
